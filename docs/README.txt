APPSTAT / LAB 01 — многостраничный HTML-сайт

Откройте index.html в браузере из этой папки. Не перемещайте HTML-файлы отдельно от папки assets.

«Содержание» открывает полное меню работы; «На этой странице» показывает подразделы; «Назад» и «Далее» соединяют страницы по порядку.
Графики открываются по нажатию в окне с увеличением, длинные графики разделены на переключаемые части.
Интерактивный генератор: generator.html — изменение seed, масштаба σ и объёма выборки, расчёт метрик, экспорт CSV.
Формулы отображаются локальной версией MathJax (SVG) без подключения к интернету.

Содержание разделов, формулы и сохранённые результаты взяты из APPSTAT_Lab01_KTvD.ipynb.
