ПОЛНАЯ КОПИЯ ПРЕЖНЕГО САЙТА APPSTAT

Это версия из репозитория eviavsis/APPSTAT-site, папка docs.
Оформление, HTML, скрипты и графики сохранены без изменений.
Последние исправления расчётов из нового ноутбука сюда не переносились.

КАК ОТКРЫТЬ
1. Распакуйте ZIP целиком («Извлечь всё»).
2. Откройте папку APPSTAT_site.
3. Дважды нажмите index.html — сайт откроется в браузере.

Все остальные HTML-страницы и папка assets должны оставаться рядом
с index.html. Не переносите отдельно один HTML-файл.

ДЛЯ GITHUB PAGES
В существующем репозитории Евы файлы лежат в docs: содержимое папки
APPSTAT_site соответствует содержимому этой папки docs.
Для отдельного нового репозитория можно загрузить содержимое
APPSTAT_site в корень и выбрать Pages: main → /(root).
Этот текстовый файл загружать необязательно.

Архив содержит только сайт. Ноутбук, таблица parquet и основной README
лабораторной для открытия сайта не требуются.
