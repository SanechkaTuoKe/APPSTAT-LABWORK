При первом открытии дождитесь загрузки Python и библиотек в браузере. Данные `load_digits` входят в scikit-learn; загружать отдельную таблицу не требуется.

Исследуем ширину и заполненность 1 797 рукописных цифр. Проверяем зависимость признаков, сравниваем отдельные цифры и пороги обработки. Генератор создаёт случайные значения ширины по измеренным частотам методом обратного преобразования.

## Быстро проверить работу

1. В разделе 1 выберите цифру и порог 3, 4 или 5. Обновятся примеры, графики и выводы.
2. Под примерами раскройте ручной расчёт ширины и числа активных ячеек.
3. Через оглавление перейдите к разделу 6 «Генератор». Измените seed и размер выборки.
4. Проследите первое случайное число по графику накопленной вероятности. Сравните доли, среднее и разброс исходных и сгенерированных значений.
5. Раскройте автоматические проверки в пункте 6.4; общий вывод находится в разделе 7.

## Локальный запуск

```bash
python -m pip install marimo numpy pandas matplotlib scikit-learn
python -m marimo run digits_marimo.py
```

Для редактирования замените `run` на `edit`. После изменения кода обновите сохранённый просмотр:

```bash
python -m marimo export html digits_marimo.py -o digits_marimo_preview.html --no-include-code --force
```
